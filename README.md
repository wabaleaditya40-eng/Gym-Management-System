# Gym Management System

A web-based Gym Management System developed using PHP and MySQL.

## 📌 Project Overview

This project provides a simple system for managing gym members, trainers,
membership plans, payments and other gym-related activities.

## 🚀 Features

### User Side
- User Registration
- User Login
- Membership Plans
- Trainer Information
- Gym Programs
- Gallery
- Contact Page
- Membership Details

### Admin Side
- Admin Login
- Admin Dashboard
- Manage Members
- Manage Users
- Manage Trainers
- Manage Plans
- Manage Programs
- Manage Gallery
- Manage Payments

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- JavaScript
- Bootstrap
- XAMPP

## 💻 Requirements

- XAMPP
- PHP 8 or later
- MySQL
- Web Browser

## ⚙️ Installation

1. Install XAMPP.
2. Copy the project into the `htdocs` folder.
3. Start Apache and MySQL from XAMPP.
4. Create a MySQL database named `gym_management`.
5. Import the provided SQL file into phpMyAdmin.
6. Configure the database connection.
7. Open the project in your browser.
